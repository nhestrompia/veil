# Agent-free MVP scope

The user confirms a minimal research browser, not a Safari or Chrome competitor. The existing AgentFreeBrowserPreview is the combined MVP candidate. Do not expand the browser interface to avoid unresolved protection work.

The functional scope is one window, an HTTPS address field, webpage rendering, back and forward navigation, reload, and a working human input route. The existing native toolbar remains. Tabs, bookmarks, browsing history, sync, extensions, a password manager, and general browser feature parity are outside this milestone.

The protection scope remains external scripts and browser protocols, accessibility reads and actions, screenshots and recordings, synthetic input, and autonomous action routes. Each result needs a working matched reference on the actual combined image. A failed client or missing permission is inconclusive. Physical completion does not transfer to a replacement process.

The current candidate is keyboard-only and supports the measured built-in keyboard with US ASCII. Those are explicit research limits. Do not silently enable ordinary input or exports to make the UI feel complete. Pointer support and broad website compatibility remain unresolved human-use requirements.

Milestone 140 tests steady window capture on the actual preview. Unfiltered capture and transition tests remain open. Preserve all permissioned images, use a new scoped helper when an old helper cannot target it, and pin its final signature before its first trust query. Keep external inspector, keyboard-observation, and autonomous-action gaps separate. The agent-free claim remains unproven until the declared acceptance gates pass.
